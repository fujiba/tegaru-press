# Tegaru Press

**Googleドキュメントで書いた記事を、画像ごと手軽に静的サイトへ。**

Tegaru Pressは、Googleドキュメントを使い慣れたライターや編集者が、技術的な知識なしにWebサイトのコンテンツを更新できるようにするためのGoogle Apps Script製ツールです。

## 主な特徴

- **いつものエディタで執筆**: Googleドキュメントの使いやすいインターフェースで記事を作成できます。
- **画像も自動処理**: ドキュメントに貼り付けた画像は自動で抽出され、記事と一緒にリポジトリへアップロードされます。
- **簡単なメタデータ管理**: 記事のタイトルや公開日などのフロントマターは、ドキュメント先頭のテーブルで直感的に管理できます。
- **ワンクリック公開**: Googleドキュメントのメニューから「GitHubへPush」を選ぶだけで、記事と画像がサイトに反映されます。

##  使い方

このツールは、サイトを管理する「開発者」と、記事を執筆する「ライター」の2つの役割を想定しています。

###  開発者向け：セットアップ

1.  **リポジトリをクローン**: このリポジトリをローカル環境にクローンします。
2.  **ライブラリのデプロイ**: `library` ディレクトリで `clasp` を使い、Google Apps Scriptプロジェクトとしてデプロイします。
3.  **テンプレートの作成**:
    -   記事執筆の元となるGoogleドキュメント（テンプレート）を作成します。
    -   `caller` ディレクトリのスクリプトを、このテンプレートにコンテナバインドスクリプトとして紐付けます。
    -   `caller` のスクリプトから、手順2でデプロイしたライブラリを紐付けます。
4.  **設定**: テンプレートドキュメントのメニュー「サイト更新 > 設定」から、GitHubリポジトリやPAT（Personal Access Token）などの接続情報を設定します。

> 詳しいデプロイ手順は `deploy_library.sh` スクリプトも参考にしてください。

### ライター向け：記事の公開フロー

1.  **記事の作成**: 開発者から共有されたテンプレートドキュメントをコピーして、新しい記事の執筆を開始します。
2.  **メタデータ入力**: メニューの「サイト更新 > フロントマターを挿入」を実行し、記事のタイトルや公開日などを入力します。
3.  **執筆と画像の挿入**: 本文を書き、必要な画像をドキュメントに貼り付けます。
4.  **プレビュー**: 「サイト更新 > Markdownプレビュー」で、実際の表示に近い形で内容を確認できます。
5.  **公開**: 執筆が完了したら、「サイト更新 > GitHubへPush」をクリック。これだけで公開作業は完了です！

## セキュリティ

GitHubのアクセストークン（PAT）は、安全性を考慮して以下の仕組みで管理されます。

- **暗号化保存**: PATは暗号化された上で、Googleドキュメントのプロパティに保存されます。
- **分離された復号ロジック**: 復号に必要な鍵はライブラリスクリプトのScriptPropertiesにのみ保存されます。これにより、ドキュメントの編集権限だけではPATを元に戻すことはできません。
- **権限の分離**: 復号関数・暗号鍵取得関数は末尾アンダースコア命名（GASのprivate規約）でライブラリ利用者から隠蔽されており、ライブラリの編集権限を持つ開発者だけがアクセスできます。
- **トークンの非公開**: 公開API `getSettings()` は暗号文のトークンも返しません（設定済みかどうかの `HAS_TOKEN` フラグのみ）。

**推奨事項**:
- Fine-grained PATを使用し、対象を公開先リポジトリ1つに限定、権限は `Contents: Read and write` のみとする。（classic PATの `repo` スコープは全リポジトリに書き込めるため非推奨）
- PATには有効期限を設定し、定期的にローテーションする。
- ライブラリスクリプトのオーナー権限・編集権限を厳格に管理する。

## 開発

開発やデプロイを補助するスクリプトを用意しています。

- **ライブラリの更新とデプロイ**:
  ```bash
  ./deploy_library.sh
  ```
- **古いデプロイのクリーンアップ**:
  ```bash
  ./rm_old_deploy.sh
  ```
- **CI/CD**: GitHub Actionsによる自動デプロイも設定済みです (`.github/workflows/deploy.yaml`)。
