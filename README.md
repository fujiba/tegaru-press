# Tegaru Press

Googleドキュメントで書いたお知らせやブログ記事を、画像も含めてたったの2クリックでGitHubにPushし、サイトを更新できる魔法のツール。

## このプロジェクトが目指すもの

FirebaseやCloudflareのような、強力で寛大な無料枠を持つモダンなサービスはたくさんあります。しかし、その恩恵を最大限に受けるには、GitやCLIといった専門知識が必要になることが多く、非エンジニアの方には敷居が高いのが現状です。

この Tegaru Press は、その「見えない壁」を取り払うための架け橋です。

UIは、誰もが使い慣れたGoogleドキュメント。

ボタンを押すだけで、裏側ではGitHubへのコミットが走り、Cloudflare PagesやFirebase Hostingなどの静的サイトが自動でデプロイされる。

この仕組みによって、専門知識がない方でも、モダンなWeb開発の恩恵を最大限に享受できるようになることを目指しています。これは、私が開発しているtegaki-deployやtegaki-relayといったOSSと思想を同じくするものです。

## 主な機能

Googleドキュメントから直接Push: 使い慣れたエディタで書いた内容を、そのままサイトに反映できます。

画像も自動アップロード: ドキュメントに貼り付けた画像も、自動で抽出し、Markdownと一緒にコミットします。

ワンクリックで複製: 既存の記事をベースに、設定ごと新しいドキュメントを複製できます。新しいお知らせの作成が簡単です。

シングルコミット: 複数の画像があっても、関連するファイルすべてを1回のコミットにまとめるため、CI/CDが無駄に実行されることはありません。

柔軟な設定: コミット先のブランチやファイルパスなどを、ドキュメントのメニューから簡単に設定できます。

## 使い方（サイト管理者向けセットアップ）

1. ライブラリの準備
   - libraryディレクトリのコードを使って、スタンドアロンのGASプロジェクトを作成し、ライブラリとしてデプロイします。- clasp を使って、スタンドアロンのGoogle Apps Scriptプロジェクトを新規作成します。ターミナルで library ディレクトリに移動し、以下のコマンドを実行してください。

   ```bash
    # Googleにログイン
    clasp login
    # "TegaruPressLibrary"という名前でプロジェクトを作成
    clasp create --type standalone --title "TegaruPressLibrary"
   ```

   - `library/src` ディレクトリにある LibraryCode.js の内容を、作成されたGASプロジェクトに反映させます。

   ```bash
   # コードをGoogleのサーバーにアップロード
   clasp push
   ```

   - 最後に、ライブラリとしてデプロイ（公開）します。

   ```bash
   # ライブラリの初回バージョンをデプロイ
   clasp deploy -d "Initial version"
   ```

   - clasp create コマンドを実行した際に library/.clasp.json ファイルが生成されます。このファイル内に書かれている scriptId が、次のステップで必要になるライブラリIDです。

2. テンプレートドキュメントの作成
   - まっさらなGoogleドキュメントを1つ作成し、これを「テンプレート」とします。
   - メニューの`拡張機能 > Apps Script`を開きます。
   - スクリプトエディタの左メニュー「プロジェクトの設定」⚙️をクリックし、「スクリプトID」をコピーします。
   - callerディレクトリの`clasp.json.sample`を`clasp.json`にコピーし、`YOUR_SCRIPT_ID`をコピーしたスクリプトIDに置き換えます。
   - `caller/src/appsscript.json`を開き、`dependencies.libraries[0].libraryId` の値を、前のステップで取得したライブラリIDに書き換えます。

3. テンプレートの設定
   - テンプレートドキュメントを開き、サイト更新 > 設定メニューから、あなたのサイトのGitHubリポジトリ情報やPAT（アクセストークン）などを設定します。
   - この設定は、ドキュメントをコピーした際に引き継がれます。
4. テンプレートの共有
   - 完成したテンプレートドキュメントを、サイトの編集者（非エンジニアの方）に**「閲覧者」**として共有します。

## 使い方（サイト編集者向け）

1. テンプレートからコピー: 共有されたテンプレートドキュメントを開き、ファイル > コピーを作成を選んで、自分用のドキュメントを作成します。
1. 設定の変更: 新しく作成したドキュメントで、サイト更新 > 設定メニューを開き、ファイルパスなど、この記事独自の設定項目を変更します。
1. 執筆: あとはいつも通り、ドキュメントに文章を書いたり、画像を貼り付けたりします。
1. 公開: 書き終わったら、サイト更新 > GitHubへPush をクリックすれば完了です。サイトが自動で更新されます。
1. 新しい記事の作成: サイト更新 > このドキュメントを複製 を使うと、現在の記事をベースに簡単に新しい記事を作成できます。

## セキュリティに関する注意

このツールは利便性を最優先するため、GitHubのアクセストークン（PAT）を`DocumentProperties`に保存します。これは、そのドキュメントの編集権限を持つ人なら誰でも、スクリプトを書き換えることでトークンを閲覧できてしまうリスクがあることを意味します。

このリスクを許容できない場合は、以下のいずれかの対策を検討してください。

- 対策1（推奨）: 個人のアカウントではなく、そのサイト専用のボットアカウントを作成し、そのアカウントのPATを使用する。
- 対策2（上級者向け）: `caller/src/Code.js`内の`USE_SCRIPT_PROPERTY_FOR_PAT`フラグを`true`に書き換え、トークンをより安全な`ScriptProperties`に保存する。詳細はコード内のコメントを参照してください。

## 開発者向け情報

ディレクトリ構成

```text
.
├── library/    # GASライブラリ本体（コアロジック）
└── caller/     # 各ドキュメントに適用するスクリプト（UIと呼び出し処理）
```
